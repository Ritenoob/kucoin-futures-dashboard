### **Bug 5: JSX Syntax Error (V4.1.1 â†’ V4.1.2)**
**Issue:** Browser showed "Unexpected token '<'" when loading dashboard  
**Root Cause:** Import statements in dashboard.jsx can't be resolved by browser Babel  
**Technical Explanation:**
- Dashboard loaded via fetch() and parsed by Babel in browser
- Browser Babel can't resolve `import ... from 'react'` statements (needs bundler)
- When Babel encountered JSX after failed import, it threw syntax error on `<`

**Fix:** Removed all import/export statements, made component global  
**Files Modified:**
- `public/dashboard.jsx` lines 1-2: Removed imports
- `public/dashboard.jsx` line 1228: Removed export

## âš ï¸ IMPORTANT TECHNICAL DETAILS

### **Why No Bundler?**
- V4 is designed for quick deployment without build step
- Uses browser Babel to parse JSX on-the-fly
- Icons defined inline to avoid package dependencies
- Trade-off: Slower initial load, simpler deployment

### **Why Inline Icons?**
- Can't use `lucide-react` package (requires bundler)
- Can't use CDN imports in JSX (module resolution)
- Solution: Define all icons as inline SVG components in index.html
- Makes them globally available for dashboard.jsx

### **WebSocket Architecture:**
- Server broadcasts to all connected clients
- Real-time position updates
- Real-time market data
- Auto-reconnection on disconnect

### **Position Persistence:**
- Saves to `positions.json` every 30 seconds
- Loads on server restart
- Prevents position loss during crashes
